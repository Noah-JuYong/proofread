# Proofread v0.1.0 출시 설계

## 목표

로컬 전체 사용자 흐름을 실제 브라우저에서 검증하고, 실패 상황의 복구 안내와 실제 화면
자료를 보강한 뒤 GitHub v0.1.0 Release를 발행한다.

## 출시 범위

- 공개 저장소 분석 → 결과 → 선택적 Codex 피드백 → Markdown 다운로드 → 이력·비교
  흐름을 Compose 환경에서 검증한다.
- 분석 API 실패에는 재시도 버튼, Codex 연결·로그인·생성 실패에는 원인별 안내와 재시도,
  Markdown 다운로드 실패에는 재시도 안내를 제공한다.
- 실제 분석 결과 화면을 캡처해 README에 추가한다.
- README에 알려진 제한 사항을 명시한다: 공개 GitHub 저장소만 지원, Codex 기능은 로컬
  선택 사항, 공용 호스팅 미제공.
- PR이 main에 병합되고 검증이 통과한 커밋에 v0.1.0 태그와 GitHub Release를 발행한다.

## 검증

Python 전체 테스트, Node Markdown 테스트, Ruff, Compose 설정 검증을 실행한다. 실제
Compose 서비스를 기동하고 브라우저에서 분석·결과·이력·비교 화면을 확인한다. Codex
피드백은 사용자 계정 사용량을 발생시킬 수 있으므로 상태·로그인 연결까지만 자동 확인하고,
실제 모델 호출은 기존 격리 어댑터 테스트로 검증한다.
