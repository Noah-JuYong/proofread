# Markdown 포트폴리오 리포트 내보내기 설계

## 목표

완료된 Proofread 분석 결과를 서버·DB 변경 없이 브라우저에서 두 개의 한국어 Markdown 파일로 다운로드한다.

## 출력 형식

- 전체 진단 리포트: 저장소 URL, 지원 직무, 총점, 카테고리 점수, 모든 finding의 우선순위·개선 제안·근거와 현재 화면의 선택적 AI 피드백을 포함한다.
- 취업 지원 요약: 점수가 높은 카테고리에서 추린 강점 최대 3개와 high/medium finding에서 추린 우선 개선 과제 최대 3개, 각 과제의 바로 실행할 행동을 포함한다.

## 구조

브라우저 app.js에 순수 변환 함수 두 개를 둔다. 함수는 완료된 AnalysisReport와 현재 보이는 AI 피드백 목록을 받고 Markdown 문자열을 반환한다. 다운로드 함수는 Blob과 임시 anchor를 사용해 전체와 요약 파일을 저장한다.

분석 완료 화면의 AI 피드백 영역 아래에 두 다운로드 버튼을 표시한다. AI 피드백이 없거나 로컬 동반 프로세스가 실행되지 않아도 두 보고서는 정상 다운로드된다.

## 경계와 보안

- 생성·다운로드는 사용자의 브라우저에서만 수행한다.
- 새 API, 데이터베이스 필드, 파일 영속화, 외부 전송을 추가하지 않는다.
- 동적 문자열은 Markdown 문맥에서 이스케이프해 제목·목록 구조를 깨지 않게 한다.
- 점수·finding의 계산과 표시 순서는 변경하지 않는다.

## 오류 처리와 검증

분석이 완료되지 않았으면 버튼을 표시하지 않는다. 브라우저가 다운로드를 막으면 UI는 짧은 재시도 안내를 표시한다. 단위 테스트는 전체 리포트에 모든 핵심 필드가 들어가는지, 요약이 세 개를 넘지 않는지, 빈 AI 피드백에서도 정상 동작하는지 확인한다. 브라우저 정적 계약, 전체 pytest, Ruff, Compose 설정 검증도 실행한다.
