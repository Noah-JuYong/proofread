# 로컬 분석 이력과 비교 설계

## 목표

로컬 PostgreSQL에 저장된 분석을 최근 순서로 조회하고, 같은 저장소의 직전 완료 분석과 현재 결과의 총점·카테고리 점수 변화를 보여 준다.

## 계약

GET /v1/analyses 는 최신 20건의 id, 저장소 URL, 직무, 상태, 완료 리포트 요약을 반환한다. 완료 리포트를 조회할 때 동일 repository_url의 더 이른 완료 분석 하나를 찾아 total_score_delta와 category_deltas를 포함한다. 이력은 기존 분석 레코드만 읽으며 새 저장소나 인증을 추가하지 않는다.

## UI

메인 화면에 최근 분석 이력 영역을 추가한다. 항목을 누르면 기존 상세 조회 결과를 다시 렌더링한다. 완료 결과에는 직전 같은 저장소 대비 총점과 카테고리 변화가 표시된다. 분석이 없는 경우에는 빈 상태만 표시한다.

## 검증

저장소 구현의 최신 정렬·20건 제한, API 목록과 비교 계산, 빈 이력, 브라우저 정적 계약을 테스트한다. 전체 pytest, Ruff, Compose 설정 검증을 수행한다.
