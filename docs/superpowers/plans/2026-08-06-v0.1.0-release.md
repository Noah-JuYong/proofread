# Proofread v0.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 오류 복구 UX와 실제 화면 자료를 갖춘 Proofread v0.1.0을 발행한다.

**Architecture:** 기존 API 계약은 유지하고 브라우저 상태 전환만 보강한다. Compose E2E에서 생성한 실제 화면을 문서 자산으로 사용하고, 병합된 main 커밋을 GitHub Release 대상으로 삼는다.

**Tech Stack:** FastAPI, vanilla JavaScript, PostgreSQL, Redis, Docker Compose, pytest, Node test, GitHub CLI

## Global Constraints

- 공개 저장소 분석과 로컬 무료 실행 범위를 유지한다.
- Codex 실제 모델 호출은 자동 E2E에서 실행하지 않는다.
- 사용자 데이터와 OAuth 자격 증명을 화면 자료·로그·Git 기록에 포함하지 않는다.
