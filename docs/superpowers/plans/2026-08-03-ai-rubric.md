# AI 엔지니어 루브릭 구현 계획

> **에이전트 작업자용:** 이 계획을 구현할 때는 `superpowers:executing-plans` 하위 스킬을 사용하고, 각 단계의 테스트를 먼저 실패시킨 뒤 최소 구현을 추가합니다.

**목표:** `ai_engineer` 분석 요청이 worker까지 전달되어 데이터·모델·평가·실험·서빙 근거 기반 리포트를 반환하게 한다.

**아키텍처:** 기존 `TargetRole`과 `evaluate(profile, target_role)` 분기를 확장한다. 새 AI category와 순수 함수는 공통 `AnalysisReport`를 반환하고, API·영속성·worker는 이미 일반화된 역할 전달 계약을 그대로 사용한다.

**기술 스택:** Python 3.12, FastAPI, Pydantic v2, Dramatiq, HTML, browser JavaScript, pytest.

## 공통 제약

- LLM 점수화, 새 GitHub API 호출, DB 마이그레이션을 추가하지 않는다.
- 기존 데이터·인프라 역할의 category·점수·finding을 변경하지 않는다.
- 누락 finding은 관련 README 섹션이 없으면 빈 evidence 배열을 반환한다.
