# Proofread v0.1.0

Proofread의 첫 로컬 우선 오픈소스 릴리스입니다.

## 주요 기능

- 데이터 엔지니어, 인프라 엔지니어, AI 엔지니어 역할별 결정론적 평가
- 모든 개선 과제에 파일·README 근거 연결
- 사용자가 직접 로그인하는 선택적 로컬 Codex AI 피드백
- 전체 진단 리포트와 취업 지원 요약 Markdown 다운로드
- 최근 20개 분석 이력과 동일 저장소 직전 결과 비교
- 분석·Codex·다운로드 실패 시 재시도 안내

## 시작하기

```bash
git clone https://github.com/Noah-JuYong/proofread.git
cd proofread
cp .env.example .env
docker compose up --build
```

브라우저에서 http://localhost:8000을 엽니다. Codex 피드백은 별도 터미널에서
`uv run proofread-codex-companion`을 실행한 경우에만 활성화됩니다.

## 검증

- Python 전체 테스트
- Markdown 변환 Node 테스트
- Ruff
- Docker Compose 설정 검사
- 실제 Compose 분석·이력·비교 E2E
- Codex companion 상태 E2E(모델 생성 제외)

## 알려진 제한 사항

- 공개 GitHub 저장소만 분석합니다.
- 공용 호스팅은 제공하지 않으며 사용자가 로컬에서 실행합니다.
- Codex 기능은 선택 사항이고 각 사용자의 ChatGPT/Codex 계정 권한과 사용량을 따릅니다.
- GitHub API 제한의 영향을 받을 수 있습니다.
